**DiDauGio** is an all-in-one tourism ecosystem for Can Tho. It combines AI-powered itinerary suggestions, interactive digital maps and service booking.

| Layer | Technologies |
| :-- | :-- |
| **Web Admin** | React, Vite, TailwindCSS, shadcn/ui |
| **Mobile App** | React Native, Expo, NativeWind |
| **Backend** | Node.js, Express, PostgreSQL, Prisma, JWT, Zod |
| **AI** | Google Gemini API |

**Highlights:** AI travel recommendations · Interactive maps · Smart itinerary planning · Integrated booking · Web and mobile experience
