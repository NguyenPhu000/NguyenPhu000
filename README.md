## About

I am a frontend-focused developer from Vietnam. I build web and mobile products with React and React Native, and I am growing my backend skills with Node.js and PostgreSQL.

- Currently working on **DiDauGio**, a smart tourism platform for Can Tho
- Interested in clean architecture, reusable components and good developer experience
- Always learning, with a current focus on TypeScript, testing and API design

## Featured Project

### [DiDauGio](https://github.com/NguyenPhu000/Didaugio) · Smart Tourism Platform for Can Tho

An all-in-one tourism ecosystem that combines AI-powered itinerary suggestions, interactive digital maps and service booking.

| Part | Technologies |
| --- | --- |
| **Web Admin** | React, Vite, TailwindCSS, shadcn/ui |
| **Mobile App** | React Native, Expo, NativeWind |
| **Backend** | Node.js, Express, PostgreSQL, Prisma, JWT, Zod |
| **AI** | Google Gemini API |

**Highlights**

- AI-powered travel recommendations
- Interactive digital maps
- Smart itinerary planning
- Integrated service booking
- Cross-platform experience on web and mobile
